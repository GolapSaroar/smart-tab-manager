# Smart Tab Manager

A productivity web application that reduces browser tab overload by organizing links and helping users close unnecessary tabs to improve system performance.

## 🌐 Live Demo

👉 https://golapsaroar.github.io/smart-tab-manager/

## Overview

Modern browsers consume significant memory when many tabs remain open. Users often keep tabs open because they do not want to lose important pages, which can slow down low-end or older computers.

Smart Tab Manager allows users to store and organize important links into categories, close unnecessary browser tabs, and quickly return to saved pages later. This reduces memory usage and provides a more organized and efficient workflow.

## Features

* Category-based link organization
* Store and manage URLs
* Search links and categories
* Add, edit, and delete categories
* Import and export data
* Multiple UI themes
* Persistent storage using browser local storage
* Responsive interface

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Browser Local Storage API

## Use Case

This tool is useful for:

* Users with low-end or older computers
* Students organizing study resources
* Developers managing documentation links
* Anyone struggling with too many browser tabs
